# 테스트 워크스페이스 데이터 준비 가이드

테스트 워크스페이스 준비용입니다. 채널 3개를 만들고 봇을 초대한 뒤, 아래 메시지를 순서대로 올립니다.

## 1. 채널 만들기

| 채널 | 공개 여부 | 확인하려는 것 |
| --- | --- | --- |
| `#general` | 공개 (기본 채널) | 멘션, 링크, 이모지, 코드 블록 변환 |
| `#study-log` | 공개 | 한국어 검색, 스레드 |
| `#staff` | **비공개** | 비공개 채널 수집 |

비공개 채널은 채널 만들기 화면에서 **비공개로 설정**을 켭니다.

## 2. 봇 초대하기

채널마다 아래 방법 중 하나로 `slackattic`을 초대합니다. 비공개 채널은 반드시 초대해야 하고, 공개 채널도 지금은 초대해 둡니다.

**방법 A: 슬래시 명령 (가장 빠름)**

채널 입력창에 입력하고 Enter:

```
/invite @slackattic
```

**방법 B: 채널 설정**

1. 채널 상단의 채널 이름 클릭
2. **통합(Integrations)** 탭 → **앱 추가(Add apps)**
3. `slackattic` 검색 → **추가**

**확인**: 채널에 "slackattic님이 채널에 참여했습니다" 메시지가 뜨면 성공입니다.

## 3. 메시지 올리기

- `↳`로 시작하는 줄은 **바로 위 메시지의 스레드 답글**로 올립니다. 메시지에 마우스를 올리고 **스레드에 답글 달기**를 누르면 됩니다.
- `@나`는 본인 계정을 멘션합니다. `@`를 입력하고 자동완성에서 고르세요.
- 이모지는 `:tada:`처럼 입력하면 자동으로 바뀝니다.
- 코드 블록은 Slack 입력창에서 ```` ``` ```` 를 입력하면 만들어집니다.

## 4. 나중에 할 일 (2주차 테스트용)

1주차 수집을 한 번 돌린 **다음 날** 아래를 해 둡니다. 2주차 스레드 재확인 기능을 테스트할 때 씁니다.

- `#study-log`의 첫 메시지("이번 주 회의 일정 정리합니다")에 **새 스레드 답글** 추가: `↳ 하루 지나서 단 답글입니다`
- `#general`의 "답글 없던 메시지" 하나에 **처음으로 스레드 답글** 추가: `↳ 원래 답글이 없던 글에 단 첫 답글`
- `#general`의 "나중에 수정할 예정" 메시지를 `이 메시지는 수정되었습니다 (수정 후)`로 **수정**
- `#general`의 "나중에 삭제할 예정" 메시지를 **삭제**

**2026-10-31 완료.** 1주차 수집기로 확인한 결과입니다.

| 작업 | 결과 |
| --- | --- |
| 기존 스레드에 새 답글 | 부모 글의 `reply_count`·`latest_reply`는 갱신. 답글 본문은 같은 날 스레드 수집을 넣은 뒤 저장됨 |
| 답글 없던 글에 첫 답글 | 위와 같음 |
| 메시지 수정 | 최신 내용과 `edited.ts`로 덮어씀 |
| 메시지 삭제 | 응답에서 빠지지만 보관본에는 그대로 남음. 같은 날 삭제 표시를 넣은 뒤 `slackattic_deleted`(발견 시각)가 붙음 |

위 결과는 메시지가 재확인 범위(채널의 마지막 메시지로부터 1일) 안에 있었기 때문입니다. 범위 밖의 오래된 메시지는 2주차 스레드 재확인에서 따로 확인합니다.
