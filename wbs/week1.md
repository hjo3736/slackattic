# slackattic 1주차 WBS: 수집기

기간: 2026-11-02 (월) ~ 2026-11-08 (일)
목표: 봇 토큰으로 채널·사용자 목록과 메시지를 증분 수집하고, 다시 실행해도 결과가 같은 수집기 완성

## 기준

**우선도**

- **P0**: 막히면 다른 작업이 진행되지 않거나, MVP의 핵심인 작업
- **P1**: 결과에 따라 계획이 바뀌는 위험 확인, 품질 보장
- **P2**: 뒤로 밀려도 일정에 영향이 적은 작업

**난이도**: 상 / 중 / 하
**담당**: 나(사용자) / Claude. Slack 가입, 앱 생성처럼 계정이 필요한 일은 직접 해야 함

| 11/6 (금) | 5.5 ~ 5.6 | **실제 워크스페이스에서 증분 수집 완료** |

**핵심 경로**: 1.3 토큰 발급 → 2.3 설정 로딩 → 3.1 API 래퍼 → 3.3 페이지네이션 → 4.3 목록 저장 → 5.3 증분 조회 → 5.5 JSONL 저장 → 5.6 실제 확인. 이 경로가 하루 밀리면 1주차 전체가 밀립니다.

**동시 진행 가능**: 6번(Pagefind 검증)과 1.2, 2.x는 토큰 없이도 할 수 있어 핵심 경로와 별개로 진행합니다.

**일정이 밀릴 때**: 8번(가이드 초안)을 2주차로 넘기고, 그래도 부족하면 7.3을 7.2와 합칩니다. 5번은 줄이지 않습니다.
